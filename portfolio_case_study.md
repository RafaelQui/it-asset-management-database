# Portfolio Case Study Copy

## IT Asset Management Database

### Problem
A fictional mid-sized company was managing hardware, software, assignments, and support requests across multiple spreadsheets. This made it difficult to maintain accurate ownership records and quickly answer basic IT operations questions.

### Solution
I designed a normalized relational database in MySQL to centralize employee, department, asset, software, assignment, and ticket information.

### What I Built
- 7 related database tables
- Primary and foreign key relationships
- Asset assignment history
- Many-to-many software installation tracking
- IT support ticket records
- Sample business data
- 12 reporting and analysis queries

### Example Business Questions Answered
- Which assets are currently assigned to each employee?
- Which departments generate the most support tickets?
- Which high-priority tickets are still unresolved?
- Which assets are available, under repair, or retired?
- Which devices should be reviewed for replacement?
- What software is installed on each device?
- What is the average support ticket resolution time?

### Skills Demonstrated
MySQL, SQL joins, aggregate functions, relational database design, data integrity, reporting, business analysis, and technical documentation.

### Interview Explanation
This project shows that I can take a business problem, identify the data that needs to be tracked, organize it into a relational model, and create SQL queries that turn operational data into useful information for decision-making.
